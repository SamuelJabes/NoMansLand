# 🎮 NoMansLand - Mobile Edition

> Top-down survival horror shooter 2D inspirado em Call of Duty Zombies

Jogo 2D da disciplina de Jogos Digitais - **Versão Mobile Android**

## 📱 Sobre o Projeto

NoMansLand é um shooter top-down onde você sobrevive a ondas de zumbis, compra armas poderosas e enfrenta um boss final. Esta é a versão mobile otimizada com controles touch intuitivos.

### ✨ Características Principais

- 🧟 Sistema de waves com spawning progressivo de zumbis
- 🔫 Sistema de armas (Pistol, Shotgun, MG)
- 💰 Economia de moedas para comprar armas e desbloquear áreas
- 🎯 Auto-aim inteligente para mobile
- 🎮 Controles virtuais otimizados para touch
- 👹 Boss fight épico com ataques variados
- 🎨 Visual horror 2D com iluminação dinâmica

## 🎯 Plataformas

- 🤖 **Android** (APK disponível) - Versão principal
- 🌐 **WebGL** (Itch.io) - Para testes no navegador

## 🚀 Como Jogar (Mobile)

### Controles
- **Joystick Virtual (Esquerda)**: Movimento
- **Botão de Disparo (Direita)**: Atirar
- **Botão E**: Interagir (comprar armas/abrir portas)
- **Auto-aim**: Mira automática no inimigo mais próximo

### Objetivo
1. Sobreviva às ondas de zumbis
2. Acumule moedas matando inimigos
3. Compre armas mais poderosas
4. Desbloqueie novas áreas
5. Derrote o boss final

## 🛠️ Tecnologias Utilizadas

- **Unity 6000.0** (6000.0.30f1 ou superior)
- **Universal Render Pipeline (URP)** 2D
- **NavMesh Plus** para pathfinding dos inimigos
- **Input System** (compatível com touch e PC)
- **Object Pooling** para otimização de performance
